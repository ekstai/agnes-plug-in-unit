# 壁纸工坊（wallpaper-studio）

给 Agnes 主界面换壁纸的界面类插件，作者：**safe**。

## 功能

- **静态壁纸**：JPG / PNG / WebP / AVIF / SVG / BMP
- **动态壁纸**：GIF / 动态 WebP，以及 MP4 / WebM / OGG / MOV 视频（自动静音循环播放）
- **两种来源**：本地文件，或粘贴 http(s) 图片/视频链接
- **显示调节**：裁剪 / 适应 / 拉伸 / 平铺 / 居中，壁纸不透明度、模糊半径、前景遮罩浓度
- **内置渐变**：暮色蓝紫、海洋青、晨曦、墨绿森林、夜空，一键应用
- 壁纸与显示参数保存在本机，重启后继续生效

## 使用

1. 在「插件 → 公开」找到「壁纸工坊」，点「导入」加入「我的」。
2. 在「我的」里确认开关为开启状态。
3. 打开「设置 → 外观」，会出现「壁纸」区域。
4. 选择本地文件或粘贴链接，按需调整填充方式与显示参数。

> 本插件是界面能力的开关包：应用识别到它安装并启用后，才会显示壁纸设置并渲染主界面壁纸；停用或移除插件后，壁纸立即停止渲染，已保存的壁纸值仍保留在偏好设置中。

## 兼容性

- 桌面版 / 网页版均可使用；视频壁纸需要浏览器支持对应编码。
- 本地文件以 data URL 保存，单文件上限 20MB；建议视频控制在 10MB 以内以保证启动速度。
- SVG 仅作为背景图渲染，不执行其中脚本。

## 版本
